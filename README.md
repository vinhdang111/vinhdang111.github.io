## 📌 Background & Scope

* **Background:** Accounting & Audit background, transitioning into Data-driven Finance (FP&A / Financial Analytics).
* **Objective:** Transform raw corporate disclosures into actionable business models, variance analyses, and dynamic dashboards using SQL, Python, and Power BI.

---

## 🚀 Featured Projects

### 1. [French Equities Financial Analysis](https://github.com/vinhdang111/french-equities-financial-analysis)
* **Stack:** SQL, Python (pandas, scikit-learn), Power BI, Jupyter Notebook
* **Overview:** End-to-end analytics covering ~50 major French-listed companies (CAC 40 / SBF 120). Includes pooled panel regression forecasting, sector profitability/leverage analysis, and an embedded Power BI dashboard.

### 2. Nestlé FP&A Case Study *(In Progress)*
* **Stack:** Excel, Power BI
* **Overview:** Simulated end-to-end FP&A workflow built on Nestlé's public financial disclosures — budget modeling, Actual vs. Budget variance analysis, and a business case for strategic expansion.

---

## 🛠️ Tech Stack & Web Architecture

* **Frontend:** Vanilla HTML5, Custom CSS3 (Responsive design, custom typography, glassmorphism UI elements)
* **Interactivity:** Vanilla JavaScript (IntersectionObserver, scroll-driven progress bar, custom cursor, magnetic button physics, count-up numbers, bidirectional skill-project filter)
* **BI Integration:** Embedded Power BI Reports
* **Hosting:** GitHub Pages
